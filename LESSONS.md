# Lessons for KOML

The domain requires an explicit reference time: a relative deadline label changes with time, so a wall-clock default would make identical inputs produce different output. Completed and cancelled tasks must remain in reconciliation totals while being separated from open deadline alerts.

Validated assumption: an eight-case planted fixture can yield exact counts and exact task membership across 200 records, including inclusive 24-hour and 72-hour boundaries. A deliberately altered deadline changed two category counts, proving calculations depend on inputs rather than expectations. This validates arithmetic under the declared policy, not Henry's need for that policy.

Unvalidated assumption: the declared priority order earns daily use. Only the private fourteen-day trial can test that.

Evidence-based improvement: adversarial saved-data coverage led to report-time recomputation from task inputs rather than trusting cached summary counts. Atomic report replacement also prevents a write failure from leaving a partial report.

Operating rule: keep planted expectations independent of production calculations, require an explicit clock input, and record real-use evidence before deciding that a correct CLI is a useful product.
